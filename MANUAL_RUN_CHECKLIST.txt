OPTION 2: MANUAL METHOD (All Platforms)
========================================

TERMINAL 1 - BACKEND:
---------------------
□ Open PowerShell/Terminal
□ Run: cd c:\Users\admin\project1\student-task-manager\backend
□ Run: pip install -r requirements.txt
□ Run: uvicorn app.main:app --reload --port 8000
□ Wait for: "Application startup complete"
□ Test: Open http://localhost:8000/health in browser
   Should see: {"status":"healthy"}


TERMINAL 2 - FRONTEND:
----------------------
□ Open NEW PowerShell/Terminal window
□ Run: cd c:\Users\admin\project1\student-task-manager\frontend
□ Run: npm install --legacy-peer-deps
   (This may take 1-2 minutes)
□ Run: npm run dev
□ Wait for: "Local: http://localhost:5173/"
□ Open: http://localhost:5173 in browser

TROUBLESHOOTING:
================

Problem: Port 8000 already in use
Solution: 
  1. netstat -ano | findstr :8000
  2. taskkill /PID <PID> /F
  OR use different port: uvicorn app.main:app --reload --port 8001

Problem: Port 5173 already in use
Solution:
  1. netstat -ano | findstr :5173
  2. taskkill /PID <PID> /F
  OR use different port: npm run dev -- --port 5174

Problem: Module not found errors
Solution:
  Backend: pip install -r requirements.txt
  Frontend: npm install --legacy-peer-deps

Problem: Database errors
Solution:
  Delete: database\student_tasks.db
  Restart backend (it will recreate)

Problem: 401 Unauthorized
Solution:
  1. Logout and login again
  2. Clear browser cookies for localhost
  3. Verify both servers are running
